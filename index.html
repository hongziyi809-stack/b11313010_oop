物件導向四大核心概念

封裝

將資料與功能整合在一起，保護內部資料。

繼承

子類別可以繼承父類別的屬性與方法。

多型

相同的方法可以依不同物件產生不同結果。

抽象

隱藏複雜細節，只呈現重要功能。

JavaScript 程式範例

class Student {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    introduce() {
        return `我是${this.name}，今年${this.age}歲`;
    }
}

const student = new Student("小明", 20);
